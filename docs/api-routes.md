# API route reference

Extracted from current Spring controller mappings. Paths describe routing, not complete request schemas or permissions. Request DTOs, `SecurityConfig` and service-level checks are authoritative. Sessions identify the caller; mutating operations require CSRF protection. Administrator routes additionally require administrator access; incident routes check ownership/team authorization.
